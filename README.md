# Indian Road Accident Dashboard

### Power BI | Data Visualization | Business Intelligence

An interactive **Power BI dashboard** designed to analyze road-accident patterns across India through key performance indicators, trend analysis, geographic comparisons, accident causes, severity, and road-type risk.

![Indian Road Accident Dashboard](Screenshot%20(34).png)

---

## Project Overview

This project transforms road-accident data into a structured dashboard that makes important patterns easier to understand at a glance.

The dashboard focuses on questions such as:

- How are accidents distributed across different years?
- Which accident causes contribute the most?
- Which states report higher accident counts?
- How does accident severity vary?
- How does road type relate to risk?
- How do accident patterns differ across states and road types?
- How can city-level filtering help explore local patterns?

---

## Dashboard KPIs

The dashboard includes high-level KPI cards for:

- **Total Accidents**
- **Total Deaths**

These provide an immediate summary before moving into detailed analysis.

---

## Analysis & Visuals

### Year-wise Accident Analysis
Shows how accident counts are distributed across the available years.

### Cause-wise Accident Analysis
Compares major accident causes, including categories such as overspeeding, distraction, poor road conditions, weather, and drunk driving.

### State-wise Accident Analysis
Highlights differences in accident counts across Indian states.

### Road-Type Risk Analysis
Compares risk scores across road types such as urban, highway, and rural roads.

### Accident Severity Analysis
Breaks accidents into severity categories to show their relative distribution.

### State & Road-Type Comparison
Compares accident counts across states while also separating them by road type.

### Interactive City Filter
A city slicer allows users to filter the dashboard and explore location-specific patterns.
