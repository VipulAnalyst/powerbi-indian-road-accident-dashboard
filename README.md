# Indian Road Accident Dashboard — Power BI

A Power BI dashboard project focused on analyzing road-accident patterns across India through KPIs, geographic comparisons, accident causes, severity, road types, and yearly trends.

## Dashboard Preview

![Indian Road Accident Dashboard](dashboard-preview.png)

## Project Objective

The goal of this project is to turn road-accident data into a clear, interactive dashboard that helps users quickly understand accident volume, deaths, major causes, severity patterns, road-risk patterns, and state-level differences.

## Dashboard Highlights

- **Total Accidents** KPI
- **Total Deaths** KPI
- Accident distribution by **year**
- Accident analysis by **cause**
- State-wise accident comparison
- Risk score analysis by **road type**
- Accident distribution by **severity**
- State and road-type comparison
- Interactive **city slicer/filter**
